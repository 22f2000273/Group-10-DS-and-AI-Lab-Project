# Training-progress and comparison figures (M4 report, Section 9)

All figures were generated by `generate_plots.py` in this folder from the
per-epoch `log.csv` inside each run folder (source of truth). No smoothing —
recorded per-epoch values are plotted as they are. No existing file was
modified; nothing was re-run. Regenerate any time with:
`python3 training/plots/generate_plots.py` (writes all PNGs again).

| figure | run(s) | source file | what it shows |
|---|---|---|---|
| curve_baseline_mass.png | unet_mass_seed42 | runs/baseline/unet_mass_seed42/log.csv | Train/validation loss and validation IoU vs epoch for the Mass baseline; best epoch 43 marked with a dashed line in both panels. |
| curve_baseline_whu.png | unet_whu_seed42 | runs/baseline/unet_whu_seed42/log.csv | Same two-panel view for the WHU baseline; best epoch 39 marked. |
| curve_baseline_inria.png | unet_inria_seed42 | runs/baseline/unet_inria_seed42/log.csv | Same two-panel view for the Inria baseline; best epoch 44 marked. |
| curves_val_iou_all_baselines.png | all three baselines (seed 42) | runs/baseline/unet_{mass,whu,inria}_seed42/log.csv | Validation-IoU convergence of the three baselines on one axis — shows WHU plateaus highest (~0.87), Inria middle (~0.72), Mass lowest (~0.65). |
| curves_seed_repeats.png | seeds 42/43/44, all datasets | runs/baseline/unet_{ds}_seed42/log.csv and runs/seeds/unet_{ds}_seed{43,44}/log.csv | Stability/convergence evidence: one panel per dataset, one line per seed; curves track closely (Δ val IoU ≤ ~0.02), and the WHU seed-44 line ends early at epoch 34 because of early stopping. |
| matrix_baseline_heatmap.png | baselines (seed 42) | runs/baseline/unet_{mass,whu,inria}_seed42/results.json | Cross-dataset test-IoU matrix as a heatmap (trained rows × tested columns) — the off-diagonal drop is visible at a glance (WHU→Mass 0.3959, Inria→WHU 0.6968 etc.). |
| diagonal_comparison_bar.png | baselines + 6 optional runs | runs/baseline/…/results.json, runs/optional/VARIANT_smp_unet_{ds}_seed42/results.json, runs/optional/FOCALFIX_{ds}_seed42/results.json | Grouped bars of in-domain test IoU: baseline vs ResNet-34 pre-trained variant vs fixed focal loss — all three methods are within ~0.03 on every dataset. |
| curves_equal_budget.png | baselines + equal-budget runs | runs/baseline/unet_{whu,inria}_seed42/log.csv and runs/equal_budget/unet_{whu,inria}_steps3450/log.csv | Equal optimiser-step budget (3,450 steps, dashed marker) vs full budget — shows how much validation IoU is still un-recovered at the subset-budget point (WHU ~0.80 vs 0.87; Inria ~0.63 vs 0.71). |

Axis conventions used in all figures: "Epoch", "Loss" (train) and
"Validation loss (BCE+Dice)" (the code computes BCE+Dice validation loss in
every run), "Validation IoU" fixed to the 0–1 range.
