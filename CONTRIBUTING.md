# Contributing Guidelines

## Coding conventions
- Follow PEP 8 for Python code.
- Keep reusable logic in `src/` and avoid hard-coding paths.
- Add/update tests in `tests/` for behavior changes.

## Branch naming
Use descriptive branch names:
- `feature/<short-description>`
- `fix/<short-description>`
- `docs/<short-description>`

## Pull request process
1. Sync with latest target branch.
2. Keep PRs focused and small.
3. Include a clear description of changes.
4. Ensure relevant tests pass.

## Team responsibilities
- Keep milestone artifacts updated in `docs/`.
- Keep datasets documented in `data/README.md`.
- Keep generated outputs under `outputs/`.
